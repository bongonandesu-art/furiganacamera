# タップ de ふりがな（Ver.1 テスト版）

住所を撮影するか、都道府県から順に選ぶと、地名の漢字の読み（ひらがな）を表示するアプリです。
OCR（Tesseract.js）と住所データは端末内で動き、外部通信は行いません。

## 使い方

1. 「データ取得」を押す（OCRエンジンの準備。最初の1回だけ）
2. 都道府県を選ぶ（分かっていれば。選ばなくても、写真から読み取れれば自動で入る）
3. 住所を撮影する（1〜2行を大きく写す）
4. 市区町村 → 町域の順に候補から選ぶ。黄色の枠が、写真の文字にいちばん近い候補
5. 読みが表示される。「読みをコピー」で貼り付け用に使える。「次の住所へ」で次の写真へ

読みは写真の文字ではなく住所データから出すので、OCRが似た文字を読み違えても正しい読みが出ます。

## ファイル構成

```
index.html              画面
js/ocr.js               OCR（Tesseract.js）。数枚ごとに作り直してメモリを解放する
js/address.js           住所データの読み込みと、写真の文字に近い順の候補づくり
build-address-data.js   日本郵便の郵便番号データから data/address/ を作る
setup.js                lib/ にOCRエンジンと日本語モデルを取得する
lib/                    OCRエンジン（setup.js が取得する）
data/address/           住所データ（build-address-data.js が作る）
```

## 準備（最初の1回）

Node.js 18 以上のPCで、このフォルダでコマンドプロンプトを開き、次を実行します。
`.js` ファイルをダブルクリックしないでください（Windowsが別の機能で開いてしまいます）。

```
node setup.js
node build-address-data.js
```

- `setup.js` … `lib/` にOCR関連のファイルを入れます。`setup.bat` のダブルクリックでも可。
- `build-address-data.js` … 日本郵便のサイトから郵便番号データを取得し、都道府県ごとの住所データを `data/address/` に作ります。
  取得できないときは、日本郵便の「郵便番号データダウンロード」のページから `utf_ken_all.zip` を保存し、
  `node build-address-data.js utf_ken_all.zip` と実行してください。
- 完了時に見本が表示されます。北海道の読みが「ほっかいどう」になっていれば正常です。
- データの利用条件は、日本郵便のダウンロードページで確認してください。

その後、`lib/` と `data/` を含めてGitHubにアップロードします（GitHub Desktop推奨）。

## うまく動かないとき

- **「住所データを取得できません」と出る**：`data/address/` がアップロードされていません。
- **メモリ不足が出る**：「計測と設定」で画像サイズを小さくするか、「メモリを整理する」を押してください。
- **候補に正しい地名が出ない**：郵便番号データは町域までで、小字や通称は入っていません。「ほかの候補を見る」や絞り込みで探してください。
