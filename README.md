# タップ de ふりがな（Ver.1 テスト版）

書類を撮影し、漢字をタップすると読み（ひらがな）をポップアップ表示するアプリです。
OCR（Tesseract.js）と辞書（kuromoji.js）はすべて端末内で動き、外部通信は行いません。

## ファイル構成

```
index.html        画面・撮影/ギャラリー・タップ判定・ポップアップ
js/ocr.js         OCRの窓口（文字と座標のリストを返す）
js/furigana.js    辞書の一括ロードと読みの取得（ロード後はメモリに保持）
js/userdict.js    ユーザー辞書の枠（Ver.1は空。IndexedDBのみ）
js/corrections.js 補正辞書（読み違える語の対応表。1行足すだけで追加できる）
lib/              Tesseract.js・kuromoji・辞書（setup.js が取得する）
setup.js          lib/ にファイルを取得するスクリプト
setup.bat         setup.js をダブルクリックで実行するための補助（Windows）
```

## 1. lib/ を用意する（最初の1回）

Node.js 18 以上が入っているPCで、次のどちらかを行います。

- `setup.bat` をダブルクリックする（Windows）
- このフォルダでコマンドプロンプトを開き、次を実行する

```
node setup.js
```

注意：`setup.js` を直接ダブルクリックしないでください。Windowsが古いスクリプト機能で開き、エラーになります。

認識モデルを変えて比較したいときは `node setup.js fast`（軽量）や `node setup.js best`（高精度）で
`lib/tesseract/lang/jpn.traineddata.gz` を入れ替えられます。

## 2. GitHub Pages で公開してスマホで開く

1. このフォルダの中身（`lib/` と `.nojekyll` も含めて）をGitHubのリポジトリにアップロードする
2. リポジトリの Settings → Pages で、Branch を `main`、フォルダを `/ (root)` にして保存する
3. 表示されたURL（`https://ユーザー名.github.io/リポジトリ名/`）をスマホで開く

## 3. テストの手順

1. 「データ取得」を押す（OCRと辞書のロード。初回は時間がかかる）
2. 「撮影する」または「ギャラリーから選ぶ」で書類の画像を入れる
3. 解析が終わったら、枠の付いた漢字をタップする
4. 画面下の「計測と設定」を開くと、各処理の所要時間を確認できる

写真を撮り直しても辞書は再ロードされません。ページを閉じるまでメモリに保持されます。

## うまく動かないとき

- **「lib/ フォルダにライブラリがありません」と出る**：`lib/` がアップロードされていないか、`node setup.js` が未実行です。
- **辞書のロードで止まる／エラーになる**：GitHub PagesのURLで開いているか確認してください（ファイルを直接開くと読めません）。`.dat.gz` が展開済みの状態で配信されるサーバーでは、kuromojiが読み込みに失敗します。
- **OCRが遅い**：「計測と設定」で画像サイズを小さくする、認識モデルを `fast` にする、を試してください。
- **文字を拾えない**：文字が横一列になるように、明るい場所で正面から撮ってください。
